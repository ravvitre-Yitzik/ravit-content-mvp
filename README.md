# Ravit Content MVP — השוואת תוכן שיווקי בין שני ספקי AI

אבטיפוס מקומי לפרויקט הגמר בקורס. אותו קלט — נתוני נכס, התרשמות אישית והוראות כתיבה קבועות — נשלח לשני ספקים: Google (Gemini) ו־Anthropic (Claude). מכל ספק מתקבלים פוסט שיווקי אחד בעברית וחמישה משפטי שיתוף. המשתמש מדרג כל חבילה בין 1 ל־5 ובוחר א׳, ב׳ או אף אחת, והכלי שומר את התוצרים, השימוש, העלות, הציונים והבחירה.

**הבחירה בטיוטה אינה אישור לפרסום.** כל תוצר נבדק ידנית: הוראות הכתיבה אוסרות להמציא עובדות, אבל המערכת אינה מבטיחה שהמודל יציית.

מסמכים: [תוכנית עבודה](docs/plan.md) · [יומן החלטות](docs/decisions.md) · [סקירת אבטחה](docs/security-review.md) · [הוראות לפרויקט](CLAUDE.md)

## עבודה מקומית שוטפת

ב־Windows אפשר להפעיל את `start-local.cmd` בלחיצה כפולה, אחרי ההתקנה הראשונית. השאירו את חלון ההפעלה פתוח ופתחו http://127.0.0.1:8765 בדפדפן. לחלופין:

```powershell
.venv\Scripts\python.exe local_ui.py --allow-work
```

הדגמה היא ברירת המחדל, ללא עלות. בחרו **עבודה**, הזינו פרטי נכס בטופס הריק או טענו במפורש דוגמה בדיונית, ובצעו **בדיקה לפני הפקה**. הבדיקה מאמתת את הקלט ומחשבת אומדן בלי לפנות לספקים. לאחר בדיקת הסיכום ואישור שליחת הנתונים ניתן להפעיל השוואה אחת — בקשה אחת לכל ספק — עד אומדן $0.50 להשוואה.

כל שינוי בנתונים מבטל את האישור הקודם. עריכה, פתיחת תוצאה שמורה ורענון אינם מפיקים תוכן חדש. הרצות העבודה נשמרות ב־`runs/work/`, בנפרד מהדגמה ומהניסוי הישן. היסטוריית העבודה ושחזור לפי מזהה פותחים תוצאות שמורות ללא חיוב נוסף; דירוג שנשמר נשאר לקריאה בלבד.

כל הנתונים שסוכמו, כולל ההתרשמות ומספר הבניין הפנימי, יישלחו ל־Google ול־Anthropic לאחר אישור במסך. מסלול Google לא אומת; ייתכן שימוש בתוכן לשיפור מוצריו במסלול החינמי. אין לשלוח מידע שאין לכם הרשאה להעביר. ההרצות והמפתחות אינם במאגר הציבורי. ראו [הפעלה ובטיחות](docs/operations.md).

המערכת מקומית למשתמש אחד בלבד. אין חשיפה לרשת או פרסום תוצרים. מסלול `live` הישן נשמר לצפייה בניסוי ההיסטורי ואינו נפתח מחדש בעקבות מצב העבודה.

## מסך הדגמה מקומי — 24.10.2026

מומש מסך אחד בעברית: נתוני נכס → שתי חבילות מדומות → דירוג ובחירה → שמירה לקריאה בלבד. ברירת המחדל היא דוגמה בדיונית. המסך אינו קורא מפתחות ואינו פונה ל־Google או ל־Anthropic; עלות וטוקנים מסומנים כלא נמדדו. אין צורך ב־API key להפעלתו.

```powershell
.venv\Scripts\python.exe local_ui.py
```

פתחו http://127.0.0.1:8765 בדפדפן באותו מחשב. לחצו על הפעלת השוואת הדגמה, דרגו את שתי החבילות ובחרו אחת או אף אחת. השמירה ננעלת; שינוי בנתוני הקלט מתחיל השוואה חדשה. תוצרי ההדגמה נשמרים תחת `runs/demo/` המוחרגת מ־Git. מספר הבניין פנימי ואינו משולב בטקסט המדומה. הבחירה אינה אישור לפרסום.

המסך תומך גם בבדיקה חיה מוגבלת, המתוארת להלן. כלי ה־CLI המקוריים נשמרו; הרצה אמיתית שלהם היא פעולה נפרדת העשויה לעלות כסף. אין עדיין מסך כללי לדפדוף בהיסטוריה.

אפיון נגיש ללא פרטים פרטיים: [docs/spec.md](docs/spec.md).

## הניסוי החי החד־פעמי — מסלול היסטורי

```powershell
.venv\Scripts\python.exe local_ui.py --allow-live
```

ברירת המחדל נשארת הדגמה. במצב חי בוחרים במפורש במסך ומאשרים עלות כוללת עד $0.50. מותרת הדוגמה הבדיונית המקורית בלבד והיא נעולה לעריכה. נדרשים שני המפתחות ב־`.env` (לפי `.env.example`); אין להזין מפתחות בדפדפן או בצ׳אט.

השירות מבצע בקשה אחת לכל ספק ללא ניסיונות חוזרים, שומר תוצאת כל ספק ומציג כשל חלקי, מודלים, שימוש ועלויות זמינות. הגבלה קבועה בתיקיית `runs/ui-live/.requests/` מאפשרת ניסוי חי יחיד גם לאחר רענון או הפעלה מחדש. אין למחוק אותה כדי לנסות שוב; בדיקה נוספת דורשת אישור חדש. פתיחת תוצאה שמורה או שמירת דירוג אינן יוצרות קריאת ספק.

קישור לתוצאה שמורה מופיע במסך לאחר ההפקה. אם התגובה אבדה, אפשר לשחזר לפי מזהה הפעולה ששמור בדפדפן, בלי להפעיל הפקה נוספת. אם אין תוצאה מלאה ומצב הקריאה אינו ודאי, השירות חוסם ניסיון חדש ושומר את המידע שכבר התקבל לבדיקה.

התקציב נבדק מקומית לפי אומדן שמרני ומגבלת פלט של 4,000 טוקנים לכל ספק; זו אינה תקרת חיוב שמוגדרת בחשבון הספק. מסלול החיוב של Google לא אומת ולכן העלות בפועל מסומנת כלא זמינה, ולצדה אומדן נפרד לפי התעריף בתשלום. גם עלות מחושבת משימוש אינה חשבונית. בדיקות pytest אינן קוראות לספקים.

ראו [מדריך הגשה ובדיקת קבלה](docs/submission.md). אין פריסה לציבור או הרשאה לפרסום תוצרים.

## דרישות

- Windows עם PowerShell (נבדק על Windows 11). אמור לעבוד גם במערכות אחרות עם התאמת נתיבים.
- Python 3.14 (נבדק על 3.14.7).
- מפתח Gemini API (Google AI Studio) ומפתח Claude API (Claude Console) — רק להרצה מול הספקים. הבדיקות המקומיות אינן צריכות מפתחות.

## התקנה

מתוך תיקיית הפרויקט:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt -r requirements-dev.txt
```

## הגדרת מפתחות

```powershell
# יוצר את .env רק אם אינו קיים, כדי לא לדרוס מפתחות קיימים
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

הדבק כל מפתח אחרי סימן השוויון, באותה שורה, ושמור. הקובץ `.env` מוחרג מהמאגר. אל תכתוב מפתחות בשום קובץ אחר.

- **Google:** במסלול החינמי (פרויקט ללא חשבון חיוב) ההפקה ללא תשלום, אבל גוגל עשויה להשתמש בתוכן לשיפור מוצריה. לכן הכלי שולח רק את הנכס הבדיוני.
- **Anthropic:** אין מסלול חינמי. גם ספירת טוקנים דורשת יתרה חיובית בחשבון. מומלץ להגדיר מגבלת הוצאה במסוף.

## הפעלה

```powershell
# בדיקות מקומיות — ללא רשת וללא מפתחות
.venv\Scripts\python -m pytest -q

# הבקשה המלאה שתישלח לספקים, מהנכס הבדיוני
.venv\Scripts\python build_prompt.py data\sample-property.json

# תוכנית ההרצה: מודלים, מגבלות ותעריפים. לא פונה לספקים
.venv\Scripts\python run_generation.py

# הרצה בפועל: קריאה אחת לכל ספק, ללא ניסיונות חוזרים. כרוכה בעלות אצל Anthropic
.venv\Scripts\python run_generation.py --run

# דירוג ובחירה להרצה שמורה (המזהה מודפס בסוף ההרצה)
.venv\Scripts\python grading.py <מזהה-הרצה>

# בנייה מחדש של הלוג המסכם runs\log.csv
.venv\Scripts\python run_log.py

# בדיקת חיבור בספירת טוקנים בלבד, ללא הפקת טקסט (פונה לספק)
.venv\Scripts\python count_tokens_gemini.py
.venv\Scripts\python count_tokens_anthropic.py
```

התוצרים נשמרים בתיקייה `runs\`, המוחרגת מהמאגר:

| קובץ | תוכן |
|---|---|
| `<מזהה>.json` | הבקשה המלאה, ההגדרות, תשובות הספקים, נתוני שימוש גולמיים, עותק התעריף ששימש, עלות ובדיקת מבנה |
| `<מזהה>.grading.json` | שיוך א׳/ב׳, ציונים, בחירה והערה. נוצר פעם אחת; קובץ ההרצה אינו משתנה |
| `log.csv` | שורה לכל חבילה עם קישור לקובץ המלא. נתון חסר נכתב ״לא זמין״, לא 0 |

## בדיקות

304 בדיקות מקומיות (pytest). קריאות לספקים מוחלפות בתשובות מדומות, ו־`tests\conftest.py` חוסם כל חיבור רשת. נבדקים, בין השאר: בדיקת הקלט ושדות החובה, בניית בקשה זהה לשני הספקים, בדיקת מבנה התשובה, חישוב עלות ונתונים חסרים, הגדרות הקריאה לספקים, דירוג, ולוג ללא כפילויות.

## מגבלות

- ההרצות מול ספקים נעשו על נכס בדיוני בלבד. הדגמה על נכס אמיתי ממתינה להחלטה על המסלול החינמי של Google.
- בכל הרצה: קריאה אחת לכל ספק, בלי ניסיונות חוזרים ובלי סבבי תיקון.
- מחשבון העלות מכסה קלט ופלט, כולל טוקני חשיבה. מטמון, כלים ואזור הפעלה לא גלובלי מסומנים ״עלות לא זמינה״. העלות מחושבת מנתוני השימוש ולא אומתה מול החיוב בפועל.
- התעריפים מוזנים ידנית ב־`data/rates.json` מהתיעוד הרשמי, ויש לעדכן אותם כשהם משתנים.
- מומש מסך הדגמה מקומי אחד; כלי המסוף נשמרו. ב־Stitch קיים **עיצוב מסכים ראשוני** של ארבעת שלבי הזרימה, שנבדק מול האפיון — עיצוב בלבד, עם תוספות קוסמטיות המפורטות ב[עיצוב המסכים](docs/ux-design.md).
- תשובות מודל משתנות בין הרצות; הרצה אחת אינה מספיקה כדי להסיק על ספק.

## כלים ומיומנויות ששימשו בפועל

הפרויקט נבנה ב־Claude Code. התכנון והמימוש נעשו באותו מודל, Claude Opus 5.5, ולא בחלוקת Opus/Sonnet שהומלצה בשיעור.

**מיומנויות Claude Code (Skills):** בעבודה על הקוד לא הופעלה אף מיומנות, ולא נוספו מיומנויות חדשות. ההנחיות האישיות הגלובליות של המשתמש (CLAUDE.md אישי: חשיבה לפני קוד, פשטות, שינויים ממוקדים ועבודה מול יעד שאפשר לאמת) נטענו אוטומטית בכל הודעה. זה קובץ הנחיות, לא מיומנות שהופעלה.

**כלים שהופעלו:**
- Obsidian, דרך חיבור MCP — תיעוד ההחלטות וההתקדמות.
- קריאה וחיפוש בתיעוד הרשמי של Google ו־Anthropic — מזהי מודלים, תעריפים, מסלול חינמי, חשיבה ופלט מובנה.
- Git — שמירות מקומיות. GitHub CLI — בדיקת התחברות בלבד.
- ספריות: google-genai 2.31.0, anthropic 1.15.0, pytest 9.1.1.

**מסמכים ששימשו כחומר מקור (לא הופעלו):**
- `ravit-post-writer` — מיומנות כתיבה קיימת של העסק (חבילה שנבנתה לשימוש מחוץ ל־Claude Code). לא הותקנה ולא הופעלה כאן; ממנה נגזר באופן גלוי קובץ הוראות הכתיבה המותאם לתרגיל.
- האפיון המאושר, האפיון המקורי, קובץ ההמשך ומסמכי ההשלמות. אלה חומרי עבודה פרטיים שאינם במאגר.
