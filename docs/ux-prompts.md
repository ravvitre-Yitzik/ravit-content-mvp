# נוסחי הבקשות ל־Stitch

הנוסחים שנשלחו לפרויקט Stitch ״רווית נכסים — השוואת טיוטות (MVP קורס)״, לשימוש חוזר או להזנה ידנית בממשק Stitch. נתונים בדיוניים בלבד.
כל המסכים: מחשב שולחני, עברית מימין לשמאל, מערכת העיצוב ״Calm Slate RTL Workspace״. אין במערכת כפתור אישור או פרסום.

## תיקון מסך 1 (השוואה חדשה)

1. להסיר את תיבת המידע ״…ולאשר את הגרסה הסופית״ ולהחליף ב: ״בחירת טיוטה אחרי ההרצה אינה אישור לפרסום. האישור הסופי נשאר שלך.״
2. להסיר ״סנכרון אחרון״.
3. להסיר מהכותרת את פעמון ההתראות, סמל העזרה ובלוק המשתמש. להשאיר שם אפליקציה, תג ״נכס בדיוני בלבד״ ושתי לשוניות.
4. להחליף את שם הקובץ המומצא ב־data/sample-property.json.
5. להסיר את שורת הגרסה, ״Engine ID״ וטקסט החברה בתחתית.
6. להסיר את התג ״100% שדות חובה מולאו״; להשאיר ״הקלט תקין — אפשר להפעיל השוואה״.
7. בכרטיס ״התרשמות רוית״: להשאיר ״שדה חובה״ ואת הטקסט הבדיוני, ולהוסיף: ״אם אין התרשמות למסור, אפשר לסמן זאת במפורש (״ללא נתון״). ההוראות אוסרות אז להמציא לרוית דעה, חוויה או זווית אישית.״ ובקר ״אין התרשמות למסור״ במצב כבוי.

לשמור את קבוצות החובה והרשות, כרטיסי כן/לא, שבבי המצב והמקרא.

- **ההפקה נעצרה לפני פנייה לספקים:** ״בקשת השלמה מרוכזת״ עם ״קומה״, ״מצב הדירה״; ״יש למסור ערך או לאשר שאינו ידוע (בשדה כן/לא אפשר גם ״לא״). סוג עסקה ומחיר חייבים להיות ידועים.״; ״נתונים סותרים: שטח גינה — יש לתקן לפני הפקה״; ״לא בוצעה קריאה ולא נוצרה עלות״.
