# גרסת הגשה — Ravit Content MVP

## מה מדגימים

כלי מקומי שמשווה שתי חבילות תוכן שיווקי בעברית מאותו קלט: Gemini ו־Claude. בכל חבילה פוסט וחמישה משפטי שיתוף. המשתמש בודק, מדרג 1–5, בוחר חבילה או אף אחת ושומר דירוג לקריאה בלבד. הבחירה אינה אישור לפרסום.

המסך בעברית כולל מסלול הדגמה ללא עלות ומסלול חי מוגבל לניסוי אחד על נכס בדיוני. שירותי הספקים, אימות הקלט, בדיקת המבנה, חישוב העלות והלוג הם קוד Python מקומי. הממשק משתמש ב־HTTP מקומי וב־JavaScript ללא ספריות צד שלישי.

## הוראות לבודק

1. פתחו את המאגר הפרטי וקראו את README ואת docs/spec.md. נדרשת הרשאת גישה למאגר; אין בקובץ זה שינוי הרשאות.
2. התקינו Python 3.14, צרו venv והתקינו requirements.txt ו־requirements-dev.txt כמפורט ב־README.
3. הריצו `.venv\Scripts\python.exe -m pytest -q`. הבדיקות חוסמות רשת ואינן דורשות מפתחות.
4. הריצו `.venv\Scripts\python.exe local_ui.py` ופתחו http://127.0.0.1:8765. השוו את הדוגמה הבדיונית, דרגו ושמרו. בדקו שהדירוג ננעל לעריכה.
5. מצב חי הוא ניסוי נפרד עם מפתחות מקומיים, אישור ותקרת עלות; אין להפעילו כחלק מהבדיקות האוטומטיות. ראו README. תוצאות שכבר נשמרו אפשר לפתוח ללא עלות נוספת באמצעות הקישור במסך.

## גבולות ומגבלות

מקומי ומשתמש יחיד בלבד; ללא פריסה, מדדי פרסום, חקר נכס, מדיה, שליחה לרשתות או מסך היסטוריה כללי. ברירת המחדל אינה עולה כסף. מסלול חי מקבל רק את הדוגמה הבדיונית המקורית; תוצאה לא ודאית אינה נשלחת שוב. תוצרי הרצות ומפתחות אינם במאגר.

הרצה אמיתית על נכס מהאפיון הפרטי לא בוצעה בשלב זה. היא דורשת החלטה נפרדת על פרטיות ועל מסלול הספקים; אין להציג את הניסוי הבדיוני כהוכחה למקרה הפרטי.

## אימות הגרסה

## חיבור חי ובדיקת קבלה — 24.10.2026

המשתמש אישר ניסוי אחד עם נכס בדיוני, בקשה אחת לכל ספק, עד $0.50 בסך הכול. נוסף LiveComparisonService המשתמש במסלול providers/evaluate הקיים. ברירת המחדל נשארת הדגמה; נדרשים opt-in בשרת ואישור במסך. הקלט החי מוגבל לדוגמה המקורית. reservation אטומי קבוע לפני הקריאה, checkpoint לכל ספק ומזהי בקשה מונעים קריאה כפולה גם אחרי הפעלה מחדש או אובדן תגובה. שחזור משתמש ב־GET לפי מזהה פעולה או הרצה ואינו מבצע הפקה.

בדיקה אמיתית יחידה נשמרה במזהה `b788e925-074e-4f11-99ca-dab02e38fd2a` (קובצי ההרצה מוחרגים). שני הספקים הצליחו, כל אחד עם פוסט וחמישה משפטי שיתוף, ללא שגיאת מבנה. Gemini דיווח 2507 טוקני קלט ו־434 פלט כולל חשיבה; Claude דיווח 3862 קלט ו־762 פלט. עלות Claude המחושבת: 0.015344 USD. Google: החיוב בפועל לא זמין כי מסלול החשבון לא אומת; אומדן לפי שימוש ותעריף בתשלום: 0.00350775 USD. הסכום עם אומדן Google הוא 0.01885175 USD, לעומת אומדן שמרני מקדים 0.0909975 USD ותקרת אישור 0.50 USD. אין לראות בסכומים חשבונית חיוב.

אימות סופי: 245 בדיקות pytest עברו ללא רשת, אזהרת התיישנות אחת בספריית Google; בדיקות תחביר JavaScript ותרחיש DOM עברו. בדפדפן אומתו opt-in, קלט נעול במצב חי, תצוגת תוצאות אמת/שימוש/עלויות, שחזור אחרי רענון ללא קריאה נוספת וכפתור הפקה מושבת. דירוג ההרצה האמיתית הושאר למשתמש; שמירת דירוג חי וקריאה בלבד אומתו בבדיקות אוטומטיות עם ספקים מדומים. לא נוצר דירוג עסקי בשם המשתמש.

ביקורת PR של שני הסוכנים והראשי: תוקנו שחזור לאחר אובדן תגובת POST, התאמת תצוגת אומדנים לחוזה ה־backend, קישורי CSV לתתי־תיקיות, והפעלת Windows עם stdout בקידוד cp1252. נוספו timeouts מפורשים של 120 שניות לקריאות הספקים ללא retries. אין ממצאי P1/P2 פתוחים מהביקורת הזאת.

בקריאת התוכן נמצאו טענות שאינן נתמכות בקלט: סופרלטיבים על מחיר נדיר/תקציב, וחזקה משתמעת בגינה (״משלכם״). לא שונו התוצרים המקוריים ולא בוצעה הפקה נוספת. זו מגבלת איכות ידועה שמצריכה בדיקה ודירוג אנושיים; תקינות מבנה אינה אישור לנכונות עובדתית או לפרסום. ניסוי על הנכס הפרטי לא בוצע ולא אושר.
